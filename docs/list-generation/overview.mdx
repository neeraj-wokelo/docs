# List Generation

Build targeted company lists using structured filters or natural language queries, enriched with detailed company data.

## What is List Generation?

List Generation allows you to create focused lists of companies based on specific criteria. Whether you need to find:

- SaaS companies in the US with Series A funding
- Private companies with 500+ employees in the healthcare sector
- AI-focused startups that raised capital in the last 12 months

List Generation gives you the flexibility to express your criteria either through precise filters or plain language descriptions.

## Two Ways to Build Lists

### Structured Filters

Apply specific, combinable filter conditions across 35+ company attributes:

- **Company Attributes**: Type, founding year, headcount, operating status
- **Location**: Headquarters country, region, city; markets served
- **Financial**: Revenue estimates, valuation bands, funding stage and amount
- **Business Model**: GTM motion, revenue model, pricing structure
- **Technology**: API availability, mobile apps, AI maturity
- **Industry**: NAICS, SIC, and Akta's industry taxonomy

### Natural Language

Describe what you're looking for in plain text:

```
"SaaS companies in the US with Series A funding founded after 2018"
```

The API interprets your intent and returns matching companies.

## How It Works

1. **Define your criteria** - Use filters or natural language
2. **Choose enrichment** - Add optional data sections (firmographics, financials, technology, etc.)
3. **Sort and paginate** - Order results by relevance or specific metrics
4. **Get results** - Receive ranked companies with requested data

## Response Structure

Each company in the response includes:

| Field | Description |
|-------|-------------|
| `uuid` | Unique company identifier |
| `name` | Company name |
| `website` | Company website |
| `sections` | Any enrichment data you requested |

Plus metadata:
- `count` - Number of results in this response
- `total_count` - Total matching companies (capped at 500)
- `credits_consumed` - API credits used
