Each akta CLI command consumes credits per call, mirroring the underlying API pricing. The tables below list the credits consumed by each command.

## Free commands

| Command | Credits Consumed |
| :-- | :-- |
| `akta-pro account` | 0 |
| `akta-pro company search <query>` | 0 |
| `akta-pro industry search <query>` | 0 |
| `akta-pro news types` | 0 |

## Company

`akta-pro company data` is billed per section, so you only pay for the sections you request.

| Command | Section | Credits Consumed |
| :-- | :-- | :-- |
| `akta-pro company data` | firmographic | 2 |
| `akta-pro company data` | business_model | 2 |
| `akta-pro company data` | company_assessment | 2 |
| `akta-pro company data` | trust_signal | 0.5 |
| `akta-pro company data` | company_hierarchy | 0.5 |
| `akta-pro company data` | digital_presence | 0.5 |
| `akta-pro company data` | financial_estimate | 0.5 |
| `akta-pro company data` | location | 0.5 |
| `akta-pro company data` | management_profile | 1.5 |
| `akta-pro company data` | product_offering | 2 |
| `akta-pro company data` | strategic_signal | 1.5 |
| `akta-pro company data` | customer_profile | 1 |
| `akta-pro company data` | industry | 1 |
| `akta-pro company data` | technology | 2 |
| `akta-pro company data` | funding_detail _(enterprise)_ | 3 |
| `akta-pro company data` | mna_and_investment _(enterprise)_ | 5 |
| `akta-pro company concise` | — | 8 |

<Note>
  Enterprise-only `company data` sections (`funding_detail`, `mna_and_investment`) are auto-skipped on lower tiers rather than billed.
</Note>

## News

| Command | Credits Consumed |
| :-- | :-- |
| `akta-pro news signals [filters]` | 0.1 + 0.01 per record |
| `akta-pro news detail <id>...` | 0.03 per record |

## Alternative signals

These commands require a Subscription or Enterprise plan. A call on a plan that doesn't cover the command returns `403`.

| Command | Credits Consumed |
| :-- | :-- |
| `akta-pro headcount <company>` | 2.5 |
| `akta-pro traffic <company>` | 1.5 |
| `akta-pro jobs <company>` | 4 credits for 10 records |
| `akta-pro posts <company>` | 1 credits for 10 records |
| `akta-pro reviews employees <company>` | 1.5 credits for 50 records |
| `akta-pro reviews products <company>` | 1.5 credits for 50 records |

<Note>
  For cost per credit and rate limits by plan, see the [Pricing](/getting-started/pricing) page.
</Note>
