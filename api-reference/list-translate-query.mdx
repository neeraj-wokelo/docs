## Overview

The List Query Translation API converts natural language descriptions into structured filter conditions. This is useful for debugging how the AI interprets your queries, or for building UI interfaces that let users switch between natural language and structured filters.

## Endpoint Details

- **Method:** POST
- **Endpoint:** `/v1/company/list/translate-query`

## Authentication requirements

- Include a valid API key in the `x-api-key` request header.

## Request

### Request Parameters

#### Header Parameters

<ParamField header="x-api-key" type="string" required>
  Your API key.
</ParamField>

#### Body Parameters

<ParamField body="query" type="string" required>
  Natural language description of the companies you want to find.

  Example: "SaaS companies in the US with Series A funding founded after 2018"
</ParamField>

## Response

#### Successful Response Fields

<ResponseField name="filters" type="object">
  Structured filter conditions equivalent to the natural language query. These can be passed directly to the List Generation API.
</ResponseField>

<ResponseField name="credits_consumed" type="float">
  Credits consumed by this request.
</ResponseField>

#### Example Response

```json 200 expandable wrap
{
  "filters": {
    "business_model.offering_type": ["saas"],
    "location.hq.country": ["USA"],
    "funding_detail.funding_overview.funding_stage": ["series_a"],
    "firmographic.founded_year": {"gte": 2018}
  },
  "credits_consumed": 1.0
}
```
